MAIN OBJECTIVE

Rebuild the DUST website into an immersive, award-level e-commerce shopping experience.

The new website must use the EXACT content, products, product information, imagery, branding, categories, pricing and data from the existing DUST website, while completely reinventing its visual presentation.

Do NOT rewrite, shorten, replace, fabricate, or simplify the existing content.

E-COMMERCE REQUIREMENT

This must be a fully designed premium e-commerce website, not simply a brand showcase website.

Build the complete shopping journey:
